# CRM +++ — public progress repository

**A closed-source CRM and AI communications platform in active development.** The goal is to connect customer conversations across phone, email, and messengers, while preserving business context, auditability, controlled AI-agent permissions, and data isolation.

**As of October 20, 2026:** a protected local CRM prototype runs; Asterisk integration and a two-turn technical voice pipeline have passed local tests; early communication adapters and a human-review foundation for proposed AI memory facts are under development. The AI memory writer, unrestricted external LLM access, and public customer service are **not enabled**. This is **not** a generally available product.

This public repository contains project descriptions, a roadmap, status reports and, once reviewed, anonymized demos. It **does not contain proprietary source code**. See the full [Russian README](README.md), [status](docs/STATUS.md), [roadmap](docs/ROADMAP.md), and [participation guidelines](CONTRIBUTING.md).

We are not currently accepting donations through this repository. No wallet addresses have been announced. Contributions via Issues should be limited to non-sensitive feedback and use cases.
