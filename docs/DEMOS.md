# Демонстрации

**Публичные видео и скриншоты ещё не опубликованы.** Мы не размещаем временные заглушки, выдаваемые за работающий продукт.

## Первый набор, который планируем подготовить

1. **CRM и направления.** Переключение тестовых направлений и просмотр обезличенной карточки контакта.
2. **История коммуникаций.** Как событие от тестового канала связано с направлением и клиентом.
3. **Голосовой сценарий.** Отрывок локального технического теста обработки звонка и голосового ответа с возможностью прерывания; отдельно указать, что автономное обслуживание реальных клиентов не включено.
4. **Контроль AI-памяти.** Защищённый экран очереди проверки на синтетических примерах, с объяснением, что автоматическое сохранение фактов ещё отключено.

## Проверка перед публикацией

- Использовать синтетические контакты, номера, адреса и тексты сообщений.
- Проверить каждый кадр на имена, почты, токены, секреты, личные контакты, серверные адреса, браузерные вкладки и уведомления.
- Не публиковать записи настоящих звонков без должных оснований и согласий.
- Убрать URL закрытых интерфейсов и сведения о сетевом периметре.
- Для каждого ролика добавить дату записи и подпись «демонстрация», «технический тест» либо «прототип».
- Отдельно проверить метаданные видео и изображений.

Ролики будут добавляться в `media/demos/` либо по проверенным ссылкам. До публикации в README нет ссылок на несуществующие демонстрации.
