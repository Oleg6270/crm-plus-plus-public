# Проверенный статус CRM +++

**Срез:** 20 октября 2026 года. Основание: внутренний мастер-журнал проекта и зафиксированные приёмочные проверки. Этот текст — публичное краткое изложение без диагностических файлов, служебных путей и пользовательских данных.

## Подтверждено в разработке

- Запущена локальная CRM с базой данных и защищённым интерфейсом; доступны структуры бизнес-направлений и коммуникационных событий.
- Интеграция с Asterisk прошла локальные функциональные испытания. Существуют обработка телефонных событий и тестовые сценарии прохождения аудио.
- Технический голосовой тест проверил две последовательные реплики, локальный STT, тестовый агент, синтез речи и прерывание прежней озвучки при новой реплике. Тестовые данные не следует трактовать как производственный SLA.
- Реализована основа учёта происхождения CRM-фактов (источник, контекст, необходимость проверки); в базе создана пустая очередь кандидатов, а в защищённых настройках — интерфейс для её просмотра.
- Разрабатываются соединения для переписки: Telegram и электронная почта. Уровень готовности отдельных маршрутов неодинаков.

## Прямо сейчас НЕ заявляем

- Готовый публичный SaaS или свободную регистрацию клиентов.
- Автоматического AI-секретаря, способного надёжно обслуживать реальных клиентов без надзора.
- Продукционное подключение облачных LLM для свободных диалогов.
- Автоматическую запись фактов AI в рабочую память CRM.
- Полностью проверенные WhatsApp/SMS/Telegram/email-маршруты для всех сценариев.
- Выполненное по всем странам юридическое соответствие обработки персональных данных.
- Готовую общую панель множества независимых CRM-инстансов.

## Открытые инженерные задачи

1. Довести цепочку сообщений до воспроизводимых end-to-end демонстраций.
2. Внедрить безопасный подтверждаемый процесс принятия AI-фактов, не отключая контроль источников и областей доступа.
3. Отдельно проверить производительность STT/голоса на оборудовании, пригодном для реальной нагрузки.
4. Реализовать роль-ограниченных рабочих AI-агентов и управляемое выполнение действий.
5. Подготовить воспроизводимое развёртывание с разделением бизнесов и стран.

**Стадия:** работа над сохранением контекста и происхождения информации, условно этап 8 из 12 внутреннего плана. Нумерация этапов служит для разработки и не означает 8/12 готового пользовательского продукта.
