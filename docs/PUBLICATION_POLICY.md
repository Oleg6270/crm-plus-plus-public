# Правила публичности и безопасности

Этот GitHub — **витрина развития закрытого коммерческого проекта**, а не его исходный репозиторий.

Можно публиковать: проверенные обезличенные демонстрации, критерии приемки без чувствительных данных, пользовательские сценарии, статус и дорожную карту.

Нельзя публиковать: полный или частичный приватный исходный код без отдельного решения правообладателя, базы данных и дампы, реальные записи клиентских разговоров, учётные данные, схемы доступа, адреса внутренних серверов, служебные логи, конфигурации маршрутизаторов и Asterisk, SSH/WireGuard-детали, персональные данные.

**Правило доказательств:** завершённый тест описывается как технический тест; локальный прототип — как локальный прототип; продуктовый релиз — только после независимой приёмки соответствующего сценария. Нельзя заменять одно другим.

Публичные демонстрации проходят отдельную проверку. Любые адреса для финансовой поддержки появятся только после проверки сетей, безопасного владения ключами, правового статуса и каналов официального подтверждения.
